# 🌌 MissionComms

**Anonymous & Secure Communication Platform**

Private, secure, and anonymous communication for sensitive or off-grid conversations.

## ✨ What MissionComms can do

- Keep conversations private & anonymous
- Run smoothly as a desktop app powered by Electron
- Secure messages using Python & Tor
- Lightweight and easy to set up

## 🛠️ Installation

Before diving in, make sure you have:

- `Python` installed
- `Tor` installed
- `Node.js & npm` installed

Then, follow these steps:
```bash
# 1. Activate your virtual environment
# (if using venv)
source venv/bin/activate  # Linux/Mac

# 2. Install Python dependencies
pip install -r requirements.txt

# 3. Navigate to the App folder
cd App

# 4. Install frontend dependencies
npm install

# 5. Start the application
npm start
```
# 🧰 Technologies Used

- **Electron** – Desktop app framework
- **Python** – Backend & core logic
- **JavaScript** – Interactive frontend
- **HTML / CSS** – Interface design
- **Tor** – Secure anonymous network
